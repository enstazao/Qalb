The pre-training checkpoint is unsloth/Meta-Llama-3.1-8B, a base model. Llama-3.1-8B-Instruct is a comparison model; do not confuse it with the starting checkpoint.

LoRA was published at ICLR 2022; the initial preprint appeared in 2021. Confirmed using the authors’ official Microsoft LoRA repository citation.

QALB Table II: rank 128, alpha 32, all linear layers plus embeddings and head, approximately 1.18B trainable parameters (14.72% of base). The parameter count belongs to this complete configuration, not to a claim about a typical LoRA-only setup.

Other settings: AdamW 8-bit; base learning rate 2e-5; embedding learning rate 2e-6; cosine decay with 0.05 warmup ratio; effective batch size 128 (16 × 8 gradient accumulation); sequence length 2048; bfloat16. Training uses Unsloth and gradient checkpointing.

Source: QALB, Table II

QALB06 / 10

Fine-tuning uses the same LoRA setup, learning rate 5e-5, two epochs, effective batch size 64, AdamW 8-bit, linear scheduling, and bfloat16. Per-device batch size is 8 with 8 gradient accumulation steps.

The official Llama 3 template distinguishes System, User, and Assistant roles using control tokens such as <|start_header_id|>. User instructions are masked from the loss, focusing learning on assistant responses.

The seven listed categories are the evaluation task coverage. Translation is bidirectional Urdu–English; reasoning includes logical and commonsense tasks.

Source: QALB, Section IV-C and Table III

QALB07 / 10

Full baseline names: Llama-3.1-8B-Instruct, Alif-1.0-8B-Instruct, Gemma-2-9b-it, Aya-expanse-8B, Mistral-Nemo-Instruct-2407, and Qwen2.5-7B-Instruct.

Following Alif, GPT-4o evaluates generated responses against ground-truth references on relevance, correctness, clarity, and formatting. The prompt uses a ten-point scale; Table IV reports scores on a 100-point scale.

The paper reports native Urdu speakers reviewing all evaluation samples and GPT-4o reasoning, with over 85% agreement. This is reported agreement in the study, not a guarantee that automated judging is unbiased.

The neutral and respectful system-instruction detail is supplied in the presentation brief. It is intended to discourage discriminatory and stereotype-reinforcing responses.

Source: QALB, Section V

All values reproduce Table IV of the arXiv paper and the user’s brief. The paper describes 90.34 and 87.1 as overall weighted averages. Alif’s simple arithmetic mean across the displayed seven task scores is approximately 87.24; that is a different calculation and has not replaced the published overall score. The task weights are not specified in the cited passage.

QALB leads on translation, ethics, reasoning, classification, sentiment analysis, and QA. Alif leads on generation (90.2 versus 85.97). The overall reported difference is 90.34 − 87.1 = 3.24 points; the QA difference is 80.40 − 73.8 = 6.60 points.

Gen. = Generation; Trans. = Translation; Reas. = Reasoning; Class. = Classification; Senti. = Sentiment analysis; QA = Question answering. Scores are judge-based benchmark scores, not classification accuracy percentages.
